# Day Boil Studios

The marketing site for [Day Boil Studios](https://dayboilstudios.com), an independent software studio founded by Jeremy Rhoades.

## Current work

Day Boil is building **Tuck**, a capture-first home for thoughts, tasks, and loose ends.

## Development

Requires Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Create a production build with `pnpm build`.

## Structure

- `/` — studio overview and current work
- `/about` — founder story and product principles
